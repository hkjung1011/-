WIP-HW-R01 · PRELIMINARY_NOT_FABRICATION

웨이퍼 결함 탐지 소형 플랫폼

고정 광학 헤드 + XY 정지 촬영 + 교환형 웨이퍼 캐리어를 먼저 구성합니다. 이송 자동화는 기존 컨베이어와 연결할 수 있도록 별도 모듈로 준비합니다.

2026-09-30 · 현재 계산 예시: 100 mm 웨이퍼 / 50 µm 결함 · 크기·두께·카메라 미확정

설계 방향

1차 장치: 영상 품질과 학습 데이터를 확보

웨이퍼를 캐리어에 수동 장착하고 XY 스테이지로 작은 영역을 순서대로 촬영합니다. 카메라와 조명은 강성 있는 독립 갠트리에 고정하고, 캐리어만 이동합니다. 조명 조건 두 가지를 같은 위치에서 비교하여 결함에 맞는 촬영 조건을 선택합니다.

이 구조는 캐리어·이송 장치가 정해지기 전에 실제 웨이퍼의 광학 조건과 파인튜닝용 데이터를 확인하는 데 적합합니다.

2차 장치: 캐리어 정지 이송과 연결

컨베이어가 캐리어를 검사 위치로 옮기고, 기계 기준면·스토퍼·위치 표식으로 위치를 확인합니다. XY 검사부와의 자동 전달은 실제 캐리어 인터페이스를 확인한 뒤 구체화합니다.

기존 60 mm 벨트의 모터와 제어 프로그램은 재사용 후보입니다. 100 mm 웨이퍼를 벨트 위에 직접 놓는 구성을 제작 기준으로 사용하지 않습니다.

아래 치수와 부품 표현은 공간 배치용 엔벨로프입니다. 가공 도면·조인트 검증·구조 해석 결과가 아닙니다. 웨이퍼 두께와 접촉 허용 조건을 받기 전에는 캐리어의 홈·클램프·진공 흡착부를 확정할 수 없습니다.

광학·타일 촬영 계산기

최소 결함은 카메라 원본과 모델 입력에서 모두 충분한 픽셀을 차지해야 합니다. 작은 결함을 찾을 때는 전체 이미지 축소보다 원본 해상도의 부분 영상 입력이 유리합니다.

카메라: 2448 × 2048, 픽셀 3.45 µm. 웨이퍼 지름의 110%를 촬영 범위로 가정합니다. 광학 타일 겹침 10%, 부분 영상 겹침 20%, 결함 폭 5 px를 검토 기준으로 사용합니다. 5 px는 이번 예시의 가정이며 검출 보장이 아닙니다.

직사각형 전 영역을 계산합니다. 웨이퍼 밖의 타일을 생략하는 경우 실제 가장자리 누락 여부를 별도로 확인해야 합니다.

5 MP 카메라의 전면 촬영과 타일 촬영

전면 수치는 10% 지름 여유를 포함합니다. 50 µm 목표에서 전면 촬영만 사용하는 100 mm 예시는 샘플링 검토 기준에 미달합니다. 타일 영상 전체를 1024로 축소하면 5 px 기준 폭이 97.7 µm로 증가합니다.

구조와 조립 기준

  • 하중 경로: 캐리어 → 상부 Y 스테이지 → X 스테이지 → 베이스. 광학 헤드는 브래킷 → 갠트리 → 같은 베이스로 연결합니다. 정확한 COTS 질량과 돌출 거리로 축 모멘트와 갠트리 처짐을 계산합니다.
  • 제안된 자유도는 캐리어 X/Y 두 축과 수동 광학 Z 조절입니다. Z는 초점 조정 후 잠금합니다. 스테이지 극한 위치에 케이블 여유와 물리적 스토퍼 공간을 남깁니다.
  • 캐리어는 웨이퍼 두께·노치·결손·뒷면 접촉 허용 여부에 따라 교환합니다. 뒷면 지지 높이, 가장자리 유지력과 이동 가속도는 실물로 확인합니다.
  • 베이스·가이드 설치 후 이동부, 캐리어, 갠트리, 광학 헤드, 조명, 배선, 암실 커버 순으로 조립하는 구조를 목표로 합니다. 실제 체결 위치와 공구 접근은 상세 CAD에서 검증합니다.

촬영·제어·파인튜닝 연결

캐리어 ID / 웨이퍼 ID 확인→타일 이동→정지·초점·안정 상태→조명 조건 A/B 촬영→원본 저장→부분 영상 추론→웨이퍼 좌표 결합

하드웨어 연결

  • PC ↔ USB3 카메라: 제조사 SDK로 원본 크기, 프레임 번호, 노출·게인과 촬영 시각을 저장합니다.
  • PC ↔ 모션 컨트롤러: 위치 요청 → READY → CAPTURE → DONE 상태를 구분하고 시간 초과·리미트·도어 상태에서 다음 이동을 중지하는 구조를 설계합니다.
  • 컨트롤러 ↔ 조명/카메라: 절연 입출력 전압·핀맵을 대조한 뒤 트리거를 연결합니다. 정지 촬영 파일럿에서는 소프트웨어 트리거로도 시작할 수 있습니다.
  • 기존 컨베이어의 구동 명령과 검사 결과 출력은 시뮬레이션 인터페이스로 먼저 연결합니다. 이 문서는 장치를 가동하거나 모터 명령을 전송하지 않습니다.

파인튜닝용 데이터

  • 원본은 wafer_id / lot_id / session_id / tile_x_y / recipe_id로 추적합니다. 정상 웨이퍼와 실제 결함 웨이퍼를 같은 촬영 조건으로 확보합니다.
  • 노출·게인·조명·배율을 고정한 뒤 라벨을 작성합니다. 여러 조명 조건을 쓰는 경우 결함이 확인되는 채널과 라벨 정책을 정합니다.
  • 부분 영상은 원본·웨이퍼 식별자를 유지합니다. 같은 웨이퍼의 타일이나 반복 촬영을 train/val/test 사이에 나누지 않습니다.
  • 50 µm 예시는 6.12 원본 px입니다. 원본 1024 px 부분 영상은 이 크기를 유지하지만 전체 축소는 2.56 px로 줄어듭니다. 패치 경계 중복을 결합하는 규칙을 검증합니다.
  • 공개 현미경 자료로 학습한 모델은 시작점입니다. 실제 장치의 새 웨이퍼에서 미검출·웨이퍼당 오경보·처리시간을 독립 평가합니다.

예시 스캔 시간: 100 mm / 20 mm FOV / 6×8 타일 / 10 mm/s / 타일당 350 ms 부대시간일 때 계산 하한 약 99.3초입니다. 가감속, 통신, 추론, 초점 조절, 로딩은 제외되어 실제 처리량으로 사용할 수 없습니다.
