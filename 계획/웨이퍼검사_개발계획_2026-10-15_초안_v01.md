# 웨이퍼 결함탐지 및 청결도 검사 개발 계획

작성일: 2026-10-15

## 목표

기존 결함 검출 앱을 정리하고, 표면에서 관찰되는 입자·오염의 지표를 추가한다. 결함 검출 결과와 청결도 측정값을 함께 보여 주되, 판정 기준은 실제 촬영 자료와 기준값을 확보한 뒤 확정한다.

## 단계별 작업

| 순서 | 작업 | 산출물 | 완료 기준 |
|---|---|---|---|
| 1 | 기존 앱 소스·설정·의존성 정리 | 실행 소스, 설치·실행 안내, 직접 만든 합성 예제 | 새 환경에서 예제 입력, 추론, 결과 저장 확인 |
| 2 | 촬영 조건과 라벨 기준 정리 | 배율·조명·해상도 기록, 정상·결함·오염 라벨 규칙, 데이터 목록 | 검출할 크기와 종류를 명시하고 웨이퍼·촬영 세션별로 학습/검증/시험 자료 구분 |
| 3 | 결함 검출 평가 및 개선 | 결함별 성능표, 누락·오검출 사례 | 별도 시험셋의 mAP·재현율과 정상 영상 오경보율 확인 |
| 4 | 청결도 지표 구현 | 입자 수·오염 면적 등 측정 결과와 화면 표시 | 기준 주석과 측정값의 오차 확인, 실제 면적 사용 시 픽셀 크기 보정 |
| 5 | 통합 검사 및 판정 검토 | 결함·청결도 결과 화면, 검사 기록 | 같은 조건의 반복 측정 편차 확인 후 허용 기준과 판정 규칙 확정 |

일정과 수치 목표는 촬영 장치, 확보 가능한 시료, 최소 검출 크기와 허용 오차를 확인한 뒤 정한다. 초기 확인은 보유 이미지로 진행하고, 장치 연동은 촬영 조건을 정한 다음 수행한다.

## 먼저 정할 항목

- 검사 대상과 범위: 웨이퍼 종류·표면 영역, 최소 결함·입자 크기, 촬영 배율·조명·해상도.
- 청결도 정의: 입자 수, 단위면적당 입자 수, 오염 면적 또는 면적 비율 중 필요한 지표와 단위.
- 판정 근거: 정상 기준 시료, 기준 주석 또는 기준 측정값, 허용 오차와 합격 기준.

## 검증 시 유의할 점

기존 test 재평가 수치는 개발 참고값으로 사용한다. 별도 시험셋은 모델 선택과 임계값 조정이 끝난 뒤 평가한다. 정상 영상도 포함해 오경보를 확인하고, 같은 웨이퍼·촬영 세션의 영상이 학습 자료와 시험 자료에 섞이지 않도록 관리한다.

공개 이미지에서 검출한 오염 클래스와 청결도 측정값은 서로 다른 결과다. 현재의 검출 mAP와 이후의 청결도 오차를 각각 기록한다.
